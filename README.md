## 0. 이번 기획에서 먼저 확정할 내용

### 0-1. 서비스가 해결할 문제

MCM SCENE FIT의 중심 문제는 단순히 `MCM의 이미지가 올드하다`는 것이 아니다. 그 표현은 설문과 인터뷰로 확인하기 전까지 가설에 가깝고, 사용자 문제보다 브랜드의 고민을 앞세운다는 한계가 있다.

서비스가 직접 해결할 문제는 다음과 같다.

> 가격대가 있는 가방을 구매하려는 사용자는 온라인에서 제품 사진과 크기를 확인할 수 있지만, 그 가방이 자신의 실제 옷차림·소지품·이동 장면에 얼마나 잘 맞을지는 판단하기 어렵다. 매장에서 확인하고 싶어도 아직 구매 확신이 없는 상태에서 직원의 응대를 받는 것이 부담스럽거나, 무엇을 확인해야 할지 몰라 방문을 미룬다.

MCM에 대한 새로운 인식은 이 문제를 해결하는 과정에서 만들어지는 결과다. 사용자가 기존 제품을 자신의 현재 생활과 여행 장면 속에서 새롭게 보게 함으로써 MCM의 여행·이동 헤리티지를 오늘의 맥락으로 연결한다.

### 0-2. 핵심 경험

> 원하는 가방을 고른다 → 내 모습에 적용해 본다 → 사용할 장면과 조건으로 검증한다 → 비교한다 → 확인할 내용과 제품이 담긴 Fit Pass로 매장 체험을 요청한다.

### 0-3. 챌린지 방향

이 서비스는 AI를 사용하지만 최종적으로는 **Challenge 02. 인터랙티브 리테일**에 더 가깝다.

- AI가 추천 문장을 만드는 데서 경험이 끝나지 않는다.
- 온라인에서 사용자가 제품을 발견하고 검증한 결과가 매장 체험 내용으로 이어진다.
- 매장에서는 이미 선택된 제품과 사용자의 확인 목적을 바탕으로 더 구체적인 체험을 제공한다.
- AI는 온라인과 매장을 잇는 개인화 도구이며, 서비스의 최종 목적은 구매 전 확신을 만드는 온·오프라인 경험이다.

### 0-4. 기능 범위

| 구분      | 내용                                                                  |
| --------- | --------------------------------------------------------------------- |
| MVP       | 구매 전 가방 탐색 · 착용 미리보기 · 조건 검증 · 비교 · 매장 체험 요청 |
| 후속 기능 | 실제 매장 재고 연동, 정교한 가상 착용, 자유로운 목적지 배경 합성      |
| 별도 확장 | 구매 후 NFC 기록 서비스 `MCM SCENE MATE`                              |

`SCENE MATE`는 구매 후 장기 관계를 다루는 별도 서비스다. 구매 전 의사결정을 다루는 `SCENE FIT`과 한 번에 구현하면 문제와 사용자 흐름이 흐려지므로, 이번 MVP에서는 브랜드 생애주기 확장안으로만 제시한다.

## 1. 프로젝트 개요

### 1-1. 제품 목표

사용자가 관심 있는 MCM 가방을 자신의 모습과 실제 사용 장면에 적용해 보고, 제품의 분위기뿐 아니라 소지품 수납·이동 방식·반복 활용 가능성까지 확인하도록 돕는다. 온라인 결과는 제품 상세 보기나 비교에서 끝나지 않고, 사용자가 직접 확인할 항목이 담긴 매장 체험 요청으로 연결한다.

초기 시제품은 공식 정보가 충분한 MCM 가방 10개를 우선 등록하고 최대 15개까지 확보한다. 제품 수보다 이미지와 사양의 정확성, 추천 근거의 설명 가능성을 우선한다.

### 1-2. 핵심 문구

| 구분      | 문구                                                               |
| --------- | ------------------------------------------------------------------ |
| 메인 카피 | **이 가방, 내 장면에서도 맞을까?**                                 |
| 서브 카피 | 내 모습과 소지품, 이동 장면으로 먼저 확인하고 매장에서 확신하세요. |
| 경험 문구 | 장면으로 보고, 조건으로 확인하고, 매장에서 확신하다.               |

### 1-3. 사용자에게 주는 가치

| 기존 경험                                              | MCM SCENE FIT 이후                                                         |
| ------------------------------------------------------ | -------------------------------------------------------------------------- |
| 제품 사진과 치수를 자신의 상황에 직접 대입한다.        | 선택한 가방이 자신의 장면에 맞는 이유와 한계를 함께 확인한다.              |
| 착용 사진이 모델 중심이라 자신의 비율을 상상해야 한다. | 자신의 사진 또는 유사한 실루엣에서 가방의 대략적인 크기와 위치를 확인한다. |
| 수납 여부를 가방 외부 치수만 보고 추측한다.            | 공식 정보에 근거해 `확인됨 · 예상됨 · 매장 확인 필요`로 구분한다.          |
| 매장에 가도 무엇을 확인해야 할지 모른다.               | 확인할 제품·색상·소지품·체험 목적이 담긴 Fit Pass를 가지고 방문한다.       |
| 온라인 탐색과 매장 경험이 단절된다.                    | 온라인 결과가 매장 체험의 시작 정보가 된다.                                |

## 2. 배경과 근거

### 2-1. 온라인과 오프라인을 함께 사용하는 구매 행동

나스미디어의 2026년 온라인 명품 구매자 분석에서는 최근 3개월 패션·잡화 구매 경로로 백화점몰·종합몰·홈쇼핑몰이 41.4%, 오프라인 매장이 40.8%로 나타났다. 온라인 구매 경험이 있는 사용자도 실물 확인을 위해 오프라인 매장을 병행하는 흐름을 보여준다. 공식몰·쇼핑몰을 통한 정보 획득은 39.1%, SNS는 38.5%였다.

이는 서비스가 온라인에서 발견과 비교를 돕되, 최종 확인을 매장으로 자연스럽게 연결해야 한다는 근거가 된다.

출처: KT 나스미디어, 2026 명품 구매자 행태 분석

### 2-2. 디지털 사용자는 예약과 구매 행동에 익숙하다

같은 조사에서 온라인 명품 구매자는 금융·생활·쇼핑 등 거래형 디지털 서비스 이용률이 전체보다 높게 나타났다. 따라서 단순한 이미지 콘텐츠보다 `제품 비교`, `확인 항목 저장`, `매장 체험 요청`처럼 다음 행동이 분명한 기능을 설계할 필요가 있다.

### 2-3. MCM 자산과의 연결

MCM은 1976년 첫 여행 제품에서 출발한 이동성과 현대적 노마드의 정체성을 브랜드 헤리티지로 설명한다. `SCENE FIT`의 장소·이동·반복 활용 중심 설계는 임의로 덧붙인 콘셉트가 아니라 MCM의 공식 서사와 연결된다.

출처: [MCM Our Heritage](https://www.mcmworldwide.com)

MCM은 현재 개인화 추천, 매장 또는 비대면 1:1 상담, 예약과 제품 관리 지원을 포함한 Concierge 경험도 운영하고 있다. 따라서 Fit Pass는 기존 매장 상담을 대체하는 기능보다, 상담 전에 고객의 조건과 확인 목적을 정리해 주는 연결 장치로 설명한다.

출처: MCM Concierge

또한 일부 제품에는 NFC 기반 Digital Product Passport가 적용되어 있다. 이는 구매 후 단계에서 `SCENE MATE`를 확장할 수 있는 브랜드 자산이지만, 이번 구매 전 MVP의 필수 기술로 포함하지 않는다.

출처: MCM Digital Product Passport

### 2-4. 팀 사전 설문에서 확인한 방향

팀이 진행한 `가격대가 있는 패션 및 가방 구매 경험 조사`에는 총 30명이 응답했다. 이 결과는 기획의 방향을 바꾸는 근거가 아니라, 앞에서 정리한 문제와 기능 우선순위가 실제 응답에서도 나타나는지 확인하는 보조 자료로 사용한다.

| 확인 내용                                              | 응답 결과                                                | 기획 반영                                                        |
| ------------------------------------------------------ | -------------------------------------------------------- | ---------------------------------------------------------------- |
| 온라인에서 가방을 찾아보거나 구매한 경험               | 19명, 63.3%                                              | 온라인 탐색 단계가 실제로 존재한다.                              |
| 온라인 탐색 후 매장을 찾는 이유                        | 직접 착용 모습 21명, 실제 크기 16명, 실제 색상·소재 16명 | 온라인이 대체하지 못하는 항목을 매장 체험으로 연결한다.          |
| 가격대 있는 가방을 온라인 정보만으로 결정하기 어려움   | `그렇다 · 매우 그렇다` 20명, 66.7%                       | 구매 전 확신 부족을 핵심 문제로 유지한다.                        |
| 정적인 사진만으로 착용 분위기를 상상하기 어려움        | `그렇다 · 매우 그렇다` 17명, 56.7%                       | 착용 미리보기를 핵심 경험으로 둔다.                              |
| 여러 페이지를 반복해 제품을 비교해야 함                | `그렇다 · 매우 그렇다` 16명, 53.3%                       | 동일 기준의 Fit Card와 비교 화면을 제공한다.                     |
| 실루엣을 통한 착용 분위기 확인 필요                    | `필요하다 · 매우 필요하다` 26명, 86.7%                   | 사진 업로드를 원하지 않는 사용자를 위한 실루엣 모드를 P0로 둔다. |
| 관심 제품 저장·비교 필요                               | `필요하다 · 매우 필요하다` 26명, 86.7%                   | 비교 기능을 추천 기능보다 먼저 완성한다.                         |
| 온라인에서 고른 제품을 매장에서 확인하도록 연결할 필요 | `필요하다 · 매우 필요하다` 28명, 93.3%                   | Store Fit Pass를 Challenge 02의 핵심 전환으로 둔다.              |

가장 이용해 보고 싶은 기능은 다음 순이었다.

1. 실루엣을 통한 착용 분위기 확인 — 10명
2. 관심 제품 저장과 비교 — 7명
3. 온라인에서 고른 제품의 매장 연결 — 6명
4. 장면에 어울리는 가방 추천 — 5명

따라서 서비스의 첫 화면을 긴 추천 문항으로 시작하기보다 **제품 선택 → 착용 미리보기 → 조건 검증 → 비교 → 매장 연결**로 구성한 현재 흐름을 유지한다.

거리·여행지 이동 체험은 5점 척도에서 4~5점을 선택한 응답자가 22명(73.3%)으로 관심은 높았다. 그러나 `화면을 불러오는 시간이 길 것 같다` 10명, `이동 과정이 번거로울 것 같다` 9명, `실제 크기나 착용감은 알기 어려울 것 같다` 8명이라는 우려도 확인됐다. 따라서 Street View형 이동은 핵심 기능이 아니라 **짧은 장면 프리셋 또는 후속 기능**으로 둔다.

다만 응답자 중 20~24세가 22명(73.3%), 대학생·대학원생이 19명(63.3%)으로 표본이 편중되어 있다. 이 결과를 전체 프리미엄 가방 소비자의 비율로 일반화하지 않고, 해커톤 MVP의 방향을 점검한 탐색 조사로만 사용한다.

### 2-5. 브랜드 인식 문제를 다루는 방식

`MCM이 올드하다`는 표현만으로 문제를 정의하지 않는다. 팀 사전 설문에서는 `예전 유행의 이미지가 강하다`에 17명(56.7%)이 동의했고, `현재 유행과 잘 연결된다`에는 2명(6.7%)만 동의했다. 반면 MCM을 이번 설문에서 처음 알았다는 응답도 11명(36.7%)이어서, 부정적 인식과 낮은 인지도를 구분해야 한다.

발표에서는 다음 두 항목을 분리해 설명한다.

1. 현재 MCM을 어떤 이미지로 인식하는가
2. MCM 제품이 자신의 일상이나 여행 장면에 어울리는 모습을 쉽게 떠올릴 수 있는가

두 번째 질문이 서비스와 더 직접적으로 연결된다. 설문에서 부정적 인식이 확인되더라도 해결 메시지는 `올드한 브랜드를 젊게 만든다`보다 다음처럼 표현한다.

> MCM이 가진 여행과 이동의 헤리티지를 사용자의 현재 장면에서 다시 경험하게 한다.

## 3. 타깃 사용자

### 3-1. 타깃 정의

연령보다 구매 상황으로 타깃을 정의한다.

> 첫 번째 또는 다음 프리미엄 가방을 알아보고 있으며, 사고 싶은 후보는 찾았지만 큰 금액을 결제하거나 매장에 가기 전에 그 가방이 자신의 옷·소지품·이동 장면에 맞는지 확인하고 싶은 사람

권장 연령 범위는 24~34세로 둘 수 있지만, 이는 핵심 조건이 아니라 설문과 마케팅 집행을 위한 보조 기준이다.

### 3-2. 포함 조건

- 최근 6개월 안에 가격대가 있는 패션 제품이나 가방을 구매했거나 구매를 고려한 경험이 있다.
- 여행, 출근, 전시, 모임, 기념일 등 구체적인 사용 장면을 염두에 두고 있다.
- 온라인에서 제품을 먼저 찾아보고 여러 상세 페이지나 후기를 비교한다.
- 디자인뿐 아니라 수납, 크기, 착용 방식, 반복 활용도를 함께 고려한다.
- 실물을 확인하고 싶지만 아직 구매 확신이 없어 매장 방문을 미루거나 부담을 느낀다.

### 3-3. 초기 핵심 페르소나

**윤서, 29세 직장인**

| 구분      | 내용                                                                                                                                                                                                                                                                      |
| --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 상황      | 2개월 뒤 도쿄 여행과 평소 주말 외출에 함께 사용할 첫 프리미엄 크로스바디백을 찾고 있다.                                                                                                                                                                                   |
| 행동      | SNS 착용 사진을 저장하고 공식몰에서 크기와 가격을 확인한다. 마음에 드는 제품은 생겼지만 모델 사진만으로 자신의 키와 옷에 어울릴지 모르겠다. 카메라와 보조배터리가 함께 들어가는지도 불확실하다. 구매할 가능성이 낮아 보일까 봐 혼자 매장에 들어가는 것도 조금 부담스럽다. |
| 원하는 것 | 매장에 가기 전에 후보를 좁히고, 방문했을 때 자신이 확인할 내용과 제품이 준비되어 있기를 원한다.                                                                                                                                                                           |

### 3-4. 제외 대상

- 단순히 MCM 제품을 구경하는 사람
- 가격 비교와 할인 정보만을 원하는 사람
- 정밀한 신체 치수 기반의 의료·산업 수준 가상 피팅을 기대하는 사람
- 이미 구매를 결정해 결제만 남은 사람
- 구매 후 기록과 리워드만을 원하는 기존 고객

### 3-5. 사용자 과업

> 프리미엄 가방을 살 때, 온라인에서 발견한 제품이 실제 내 생활과 모습에 맞는지 미리 확인해 후보를 좁히고, 매장에서는 꼭 필요한 것만 확실히 확인하고 싶다.

## 4. 문제 정의

### 4-1. 사용자 여정에서 발생하는 문제

| 단계           | 사용자 행동                            | 현재 불편                                       | 기회                                            |
| -------------- | -------------------------------------- | ----------------------------------------------- | ----------------------------------------------- |
| 구매 계기      | 여행·출근·모임을 앞두고 가방을 찾는다. | 어떤 기준으로 골라야 할지 모호하다.             | 사용 장면을 선택 기준으로 바꾼다.               |
| 온라인 탐색    | SNS, 후기, 공식몰을 오간다.            | 서로 다른 사진과 정보가 흩어져 있다.            | 공식 정보와 장면 정보를 한 화면에서 정리한다.   |
| 후보 선택      | 마음에 드는 가방을 저장한다.           | 자신의 키·옷·분위기에서 어떤지 상상하기 어렵다. | 사용자 사진 또는 유사 실루엣에 제품을 적용한다. |
| 실용성 검증    | 크기와 수납을 추측한다.                | 외부 치수만으로 실제 수납을 확정하기 어렵다.    | 근거 수준을 구분하고 매장 확인 항목을 만든다.   |
| 매장 방문 판단 | 실물을 보고 싶어 한다.                 | 구매 확신이 없고 직원 응대가 부담스럽다.        | 제품과 체험 목적을 미리 전달한다.               |
| 최종 결정      | 여러 후보를 다시 비교한다.             | 디자인과 실용성의 장단점을 한눈에 보기 어렵다.  | 동일 기준의 Fit Card로 비교한다.                |

### 4-2. 핵심 문제 세 가지

1. **장면 불확실성:** 제품이 자신의 옷차림과 방문 장소에 어울리는지 판단하기 어렵다.
2. **사용 불확실성:** 필요한 소지품이 들어가는지, 이동 중 편한지, 이후에도 자주 쓸지 판단하기 어렵다.
3. **방문 불확실성:** 실물을 확인하고 싶지만 매장 방문 전 확신이 부족하고, 무엇을 요청하고 확인해야 할지 모른다.

### 4-3. POV

> 구체적인 여행이나 일상 장면을 앞두고 프리미엄 가방을 고민하는 사용자는 온라인 정보만으로 제품이 자신의 모습과 실제 사용 조건에 맞는지 확신하기 어려우므로, 매장 방문 전에 후보를 개인화된 장면과 조건으로 검증하고 방문 목적까지 정리할 방법이 필요하다.

### 4-4. HMW

> 어떻게 하면 사용자가 MCM 가방을 자신의 실제 장면에서 먼저 경험하고, 불확실한 부분만 매장에서 부담 없이 확인하게 할 수 있을까?

## 5. 해결 방안

MCM SCENE FIT은 `추천만 해주는 AI`가 아니라 **구매 전 확신을 단계적으로 만드는 경험**이다.

### 5-1. 핵심 구조

1. **Scene Preview:** 선택한 가방을 자신의 사진 또는 유사 실루엣에 적용해 대략적인 크기와 분위기를 본다.
2. **Fit Check:** 장면, 이동량, 소지품, 착용 방식, 반복 사용 장면을 제품 정보와 비교한다.
3. **Fit Card:** 잘 맞는 점, 맞지 않는 점, 정보의 확실성, 매장에서 확인할 내용을 한 장에 정리한다.
4. **Store Fit Pass:** 확인하고 싶은 제품·색상·체험 내용을 선택해 매장 체험을 요청한다.

### 5-2. 차별점

| 일반적인 패션 추천               | MCM SCENE FIT                                                 |
| -------------------------------- | ------------------------------------------------------------- |
| 취향에 맞는 제품을 나열한다.     | 사용자가 먼저 고른 제품을 실제 장면과 조건으로 검증한다.      |
| 장점 위주로 설명한다.            | 잘 맞는 점과 구매 전 확인할 점을 함께 보여준다.               |
| AI가 모든 항목을 추론한다.       | 공식 제품 정보, 규칙 기반 판단, AI 설명을 분리한다.           |
| 온라인에서 추천이 끝난다.        | 결과가 매장 체험 목적과 요청 정보로 이어진다.                 |
| 합성 이미지의 사실성만 강조한다. | 공식 제품 이미지를 보존하고, 미리보기의 한계를 명확히 알린다. |

## 6. 최종 사용자 흐름

### 6-1. 진입 방식

MVP의 기본 진입은 `궁금한 가방이 있어요`로 한다.

- **기본:** 궁금한 가방이 있어요 → 제품 선택 후 Fit Check
- **보조:** 어떤 가방이 맞을지 모르겠어요 → 조건 입력 후 후보 추천

추천을 첫 단계로 강제하지 않는 이유는 사용자가 이미 SNS나 공식몰에서 마음에 드는 후보를 발견한 상황을 반영하고, 입력 전에 제품을 보여줘 이탈을 줄이기 위해서다.

### 6-2. 전체 흐름

#### STEP 1. 원하는 제품 선택

- 가방 형태, 색상, 가격, 착용 방식을 기준으로 제품을 살펴본다.
- 관심 제품 한 개를 선택한다.
- 제품별 공식 이미지와 핵심 사양을 사용한다.

#### STEP 2. 내 모습에서 미리 보기

사용자는 두 가지 방식 중 하나를 고른다.

- 내 전신 사진 업로드
- 키와 체형이 비슷한 준비된 실루엣 선택

MVP에서는 공식 제품 이미지를 2D 레이어로 배치한다. 생성형 AI가 제품을 다시 그리지 않으므로 로고·패턴·색상 왜곡을 줄일 수 있다. 결과는 정확한 가상 피팅이 아니라 `크기와 분위기를 가늠하는 미리보기`임을 표시한다.

사용자는 필요할 경우 가방 위치와 크기를 직접 미세 조정할 수 있다.

#### STEP 3. 사용할 장면과 조건 입력

필수 입력은 네 가지로 줄인다.

1. **장면:** 여행, 출근, 전시·문화생활, 약속·모임, 데일리
2. **이동량:** 실내 중심, 가벼운 도보, 오래 걷기
3. **소지품:** 휴대전화, 지갑, 파우치, 태블릿, 13인치 노트북, 소형 카메라, 350mL 물병 등
4. **선호 착용 방식:** 토트, 숄더, 크로스바디, 백팩

선택 입력은 두 가지다.

- 여행 또는 방문 장소·시기
- 특별한 일정 이후 다시 사용할 장면

기존의 여섯 가지 조건은 삭제하지 않고 `필수 4개 + 선택 2개`로 재구성한다. 날씨는 사용자가 직접 답하는 질문이 아니라 목적지와 시기를 바탕으로 참고 정보를 불러오는 항목으로 둔다. 다만 소재의 방수성이나 기후 적합성은 공식 관리 정보가 있을 때만 판단한다.

#### STEP 4. Scene Fit 결과 확인

결과는 하나의 총점보다 세 축으로 보여준다.

| 지표             | 확인 내용                                  | 출력 예시                                                      |
| ---------------- | ------------------------------------------ | -------------------------------------------------------------- |
| Scene Match      | 선택한 장면·옷 분위기와 제품의 스타일 조화 | `도시 여행 장면과 잘 어울림`                                   |
| Carry Check      | 소지품 수납과 착용 방식 충족 여부          | `휴대전화·지갑은 확인됨 / 카메라와 물병 동시 수납은 확인 필요` |
| Rewear Potential | 특별한 일정 이후 반복 활용 가능성          | `주말 외출과 전시 관람에 반복 활용 가능`                       |

결과 카드에는 다음 내용을 함께 제공한다.

- 이 가방이 잘 맞는 이유
- 가장 잘 맞지 않는 조건
- 구매 전에 확인할 점
- 정보 근거 수준
- 조건을 바꾸었을 때의 대안 제품 한 개

#### STEP 5. 비교와 최종 선택

사용자는 처음 고른 가방과 대안 제품을 동일한 기준으로 비교한다.

- 내 모습에서의 크기와 위치
- Scene Match
- Carry Check
- Rewear Potential
- 확인이 필요한 항목
- 가격과 공식 상세 페이지

대표 제품을 억지로 추천하지 않는다. 필수 조건을 충족하지 못하면 `현재 선택한 조건을 모두 만족하는 제품을 찾지 못했습니다`라고 안내하고, 바꿀 수 있는 조건과 매장에서 확인할 내용을 제시한다.

#### STEP 6. Store Fit Pass 발급

사용자는 매장에서 받고 싶은 경험을 고른다.

- 실제 착용 비율과 스트랩 길이 확인
- 가져갈 소지품 수납 테스트
- 내 옷과 어울리는 스타일링 제안
- 다른 색상과 대안 제품 비교
- 제품 관리와 오래 사용하는 방법 상담

Fit Pass에는 다음 정보가 담긴다.

- 선택 제품과 색상
- 비교 제품
- 선호 매장과 방문 희망 시간
- 선택한 체험 목적
- 사용자가 직접 확인하고 싶은 항목

MVP에서는 실제 예약 확정이나 실시간 재고 차감까지 구현하지 않는다. `재고 및 체험 가능 여부 확인 요청`을 접수하고, 데모에서는 확인 중·확인 완료 상태를 예시 데이터로 보여준다.

### 6-3. 현장 부스용 60초 흐름

1. QR로 모바일 웹 접속
2. 준비된 대표 가방 한 개 선택
3. 준비된 실루엣 또는 자신의 사진 선택
4. 대표 장면·이동량·소지품 빠른 선택
5. Scene Fit Card 확인
6. 가상 Store Fit Pass 생성

개인 사진 촬영과 상세 입력을 포함한 일반 흐름은 약 2~3분, 준비된 선택지를 사용하는 행사 체험 흐름은 60초 이내를 목표로 한다.

## 8. 기능 명세

### 8-1. 제품 데이터베이스

제품마다 다음 정보를 등록한다.

| 구분   | 필드                                                           |
| ------ | -------------------------------------------------------------- |
| 기본   | 제품명, 제품 번호, 카테고리, 색상, 가격, 공식 상세 URL         |
| 크기   | 가로, 세로, 폭, 공식 표기 사이즈                               |
| 착용   | 토트·숄더·크로스바디·백팩 여부, 스트랩 길이와 조절 여부        |
| 수납   | 공식적으로 안내된 수납 품목, 포켓 수, 지퍼·잠금 방식           |
| 소재   | 공식 소재 설명과 관리 주의사항                                 |
| 이미지 | 정면 제품 이미지, 착용 이미지, 투명 배경 이미지 사용 가능 여부 |
| 태그   | 장면, 격식도, 스타일 무드, 반복 활용 장면                      |
| 근거   | 정보 출처 URL, 확인일, 공식 확인 여부                          |

제품 크기만으로 가방 내부의 정확한 용량을 계산하지 않는다. 외부 부피를 실제 수납 용량으로 간주하거나, 임의로 `90% 찼다`고 표현하면 안 된다.

### 8-2. 수납 판정

| 상태           | 기준                                                | 표현 예시                                                |
| -------------- | --------------------------------------------------- | -------------------------------------------------------- |
| 확인됨         | 공식 설명에서 해당 품목 수납을 명시                 | `13인치 노트북 수납이 공식 확인되었습니다.`              |
| 예상됨         | 제품 치수상 가능성이 있지만 내부 구조는 미확인      | `크기상 가능성이 있으나 실제 배치는 달라질 수 있습니다.` |
| 매장 확인 필요 | 내부 구조 또는 동시 수납 여부를 알 수 없음          | `카메라와 물병 동시 수납은 매장에서 확인해 주세요.`      |
| 어려움         | 공식 치수나 구조상 필수 조건을 명백히 충족하지 못함 | `선택한 노트북 크기보다 가방 폭이 작습니다.`             |

### 8-3. 추천·검증 로직

1. **필수 조건 확인:** 착용 방식, 공식 수납 조건, 크기 제한
2. **장면 적합도 계산:** 장면 태그와 제품 스타일 태그 비교
3. **이동 적합도 계산:** 이동량과 제품 무게·착용 방식 비교. 공식 무게가 없으면 판단하지 않는다.
4. **반복 활용도 계산:** 사용 후 장면과 제품 태그 비교
5. **근거 문장 생성:** 규칙 결과를 AI가 이해하기 쉬운 문장으로 정리

AI가 사실을 새로 만드는 구조가 아니라, 사용자의 자연어를 조건으로 정리하고 규칙 기반 결과를 설명하는 구조를 사용한다.

### 8-4. 사진 업로드와 미리보기

MVP에서는 목둘레·허리둘레·허벅지둘레 등 신체 치수를 받지 않는다. 가방의 대략적인 비율 확인에 비해 입력 부담과 개인정보 민감도가 지나치게 크기 때문이다.

권장 흐름은 다음과 같다.

- 촬영 가이드 프레임 제공
- 카메라를 가슴 높이 부근에 두고 수평 안내
- 전신이 프레임 안에 들어오도록 유도
- 사진 업로드 후 사람 영역을 분리하거나 준비된 실루엣 사용
- 어깨·손·골반 기준점에 가방 이미지 배치
- 사용자가 위치와 크기를 직접 조정
- 결과 화면에 `실제 제품 크기와 착용감은 매장에서 확인이 필요합니다` 표시

생성형 이미지 모델이 제품을 다시 그리는 방식은 로고·패턴·색상·스트랩을 변형할 수 있으므로 MVP의 기본 방식으로 사용하지 않는다.

### 8-5. Store Fit Pass

| 필드        | 내용                                                    |
| ----------- | ------------------------------------------------------- |
| 사용자 선택 | 제품, 색상, 대안 제품, 희망 매장과 시간                 |
| 체험 선택   | 착용 비율, 스트랩, 수납, 스타일링, 색상 비교, 관리 상담 |
| 시스템 정리 | 잘 맞는 조건, 확인이 필요한 조건, 사용자 질문           |
| 매장 응답   | 요청 접수, 제품 확인 중, 체험 가능, 일정 조율 필요      |

실제 적용 시 매장 직원 화면과 고객용 화면을 분리한다. 해커톤 MVP에서는 고객용 요청과 접수 완료 화면까지만 구현한다.

## 9. AI의 역할

### AI가 하는 일

- 사용자가 입력한 문장에서 장소, 일정, 활동, 원하는 분위기를 정리한다.
- 장면과 제품에 붙은 스타일 태그의 유사성을 계산한다.
- 규칙 기반 수납·착용 결과를 이해하기 쉬운 문장으로 설명한다.
- 선택 제품과 대안 제품의 장단점을 동일한 형식으로 요약한다.
- Fit Pass에 사용자가 매장에서 확인할 질문을 자동 정리한다.

### AI가 하지 않는 일

- 공식 정보가 없는 방수성, 내구성, 수납 가능 여부를 확정하지 않는다.
- 가방 외부 치수만으로 내부 용량을 정확히 계산하지 않는다.
- 생성 이미지의 제품 외형을 실제 제품과 동일하다고 주장하지 않는다.
- 사용자의 성격이나 감정을 사진만으로 분석하지 않는다.
- 실시간 재고 데이터가 없는데 재고가 있다고 표시하지 않는다.

## 10. 온·오프라인 연결 설계

### 온라인에서 준비하는 것

- 관심 제품과 대안 제품
- 자신의 사용 장면
- 필요한 소지품
- 선호 착용 방식
- 확인이 필요한 항목
- 매장에서 원하는 체험

### 매장에서 완성하는 것

- 실제 색상과 소재 확인
- 체형 대비 크기와 스트랩 길이 확인
- 선택 소지품의 실제 수납 테스트
- 대안 제품과 비교 착용
- 관리 방법과 장기 사용 상담

### 매장 경험의 핵심 원칙

매장 방문을 단순히 `사러 가기`로 만들지 않는다. 사용자가 온라인에서 남긴 질문을 매장에서 해결하는 **예약된 검증 경험**으로 만든다.

> “이 제품을 보여주세요”가 아니라
> **“이 가방에 카메라와 물병이 함께 들어가는지, 제 키에서 크로스바디 길이가 맞는지 확인하고 싶어요”**라고 말할 수 있게 한다.

## 11. 경쟁 서비스와 참고 전략

### 코치에서 참고할 점

코치는 가방과 액세서리에 스탬프·모노그램·참 등을 더해 제품을 자기표현 수단으로 바꾸는 커스터마이징 경험을 제공한다. MCM SCENE FIT은 제품을 직접 변경하는 대신 사용자의 장면을 제품에 연결해 자기표현을 돕는다.

출처: Coach Customization

### MCM SCENE FIT의 차이

- 광고 캠페인처럼 완성된 이미지를 일방적으로 보여주지 않는다.
- 사용자가 자신의 장면과 조건을 넣어 결과를 만든다.
- 시각적 재미에서 끝나지 않고 수납·착용·반복 활용을 확인한다.
- 온라인 결과가 매장 체험 정보로 이어진다.

### 경쟁 비교 시 주의할 점

마이클 코어스 AR, 롱샴 3D·커스터마이징 등 사례는 실제 기능이 현재도 운영되는지와 적용 국가를 발표 전에 다시 확인해야 한다. 과거 캠페인을 현재 상시 서비스처럼 표현하지 않는다.

## 12. 성공 지표와 검증 방법

### 12-1. 핵심 지표

**사용자 가치 지표**

- 체험 전후 제품 선택 확신이 5점 척도에서 평균 1점 이상 상승
- 추천 이유와 확인 필요 항목을 이해했다는 응답 70% 이상
- 처음 선택한 제품과 대안 중 하나를 최종 후보로 정한 비율 50% 이상

**행동 지표**

- Scene Fit 완료율 70% 이상
- 제품 비교 화면 이용률 40% 이상
- 제품 상세 보기 · 저장 · Store Fit Pass 중 하나를 선택한 비율 35% 이상
- Store Fit Pass 생성률 20% 이상

**신뢰 지표**

- 공식 정보와 다른 수납 확정 사례 0건
- 실시간 재고 연동 없이 재고를 확정 표시한 사례 0건
- 조건을 충족하지 못한 제품을 근거 없이 대표 추천한 사례 0건

### 12-2. 부스 검증 방식

1. 체험 전 관심 제품의 구매 확신을 5점으로 질문한다.
2. 60초 빠른 흐름을 체험하게 한다.
3. 체험 후 구매 확신과 결과 이해도를 다시 질문한다.
4. 상세 보기, 비교, Fit Pass 중 실제로 누른 행동을 기록한다.
5. 가장 도움이 된 요소와 불필요한 요소를 한 개씩 선택하게 한다.

### 12-3. 설문으로 검증할 가설

| 가설                                                  | 확인 질문 방향                                    | 기능 결정                 |
| ----------------------------------------------------- | ------------------------------------------------- | ------------------------- |
| 자신의 모습에서 제품 크기와 분위기를 상상하기 어렵다. | 온라인 사진만으로 착용 모습을 판단하기 어려웠는가 | 사진 미리보기의 우선순위  |
| 수납과 이동 편의가 구매 지연 원인이다.                | 가방 구매 전 가장 확인하기 어려운 조건은 무엇인가 | Fit Check 항목의 비중     |
| 온라인 탐색 후 실물 확인을 병행한다.                  | 제품 탐색·비교·구매 채널을 단계별로 질문          | 온·오프라인 흐름의 타당성 |
| 구매 확신 전 매장 응대가 부담스럽다.                  | 방문을 미룬 경험과 구체적인 이유                  | Fit Pass의 필요성         |
| 목적이 정해진 예약은 방문 의향을 높인다.              | 제품·재고·체험이 준비된다면 방문할 의향           | 매장 요청 기능의 우선순위 |
| MCM을 현재 자신의 장면과 연결하기 어렵다.             | 브랜드 이미지와 사용 장면 연상 정도를 분리 측정   | 브랜드 인식 메시지의 근거 |

설문 결과에서 `매장 응대 부담`이 낮게 나오더라도 Store Fit Pass를 바로 폐기할 필요는 없다. 재고 확인, 방문 효율, 체험 목적 사전 전달 중 어떤 가치가 더 큰지 세부 응답을 나누어 판단한다.

| 가상 착용의 과장 | 단일 사진으로 실제 착용감과 크기를 정밀하게 계산하기 어렵다. | `미리보기`로 명명하고 수동 조정과 매장 확인을 제공한다.                       |
| 수납 오판        | 외부 치수와 내부 사용 가능 공간은 다르다.                    | 네 단계 근거 표시와 실제 수납 체험을 연결한다.                                |
| 입력 이탈        | 사진과 여섯 문항을 모두 요구하면 이탈할 수 있다.             | 실루엣 대안, 필수 4개, 60초 빠른 모드를 제공한다.                             |
| 개인정보         | 전신 사진은 민감하게 느껴질 수 있다.                         | 선택 동의, 최소 보관, 즉시 삭제 옵션, 실루엣 대안을 제공한다.                 |
| 재고 신뢰        | 내부 API 없이 실시간 재고를 제공할 수 없다.                  | `재고 확인 요청`으로 표현하고 데모 데이터임을 표시한다.                       |
| 브랜드 톤        | 지나친 귀여움이나 게임화가 프리미엄 경험을 약화할 수 있다.   | 구매 전 서비스는 세련되고 기능적으로, 게임화는 구매 후 SCENE MATE에서 다룬다. |
| 범위 과다        | 7개 기능을 모두 구현하면 핵심 경험이 완성되지 않을 수 있다.  | P0 여섯 기능을 먼저 완결하고 P1 · P2는 발표용 확장안으로 구분한다.            |

## 16. 발표용 핵심 논리

### 문제

> 가격대가 있는 가방은 온라인 사진만 보고 사기 어렵지만, 구매 확신이 없는 상태에서 매장에 들어가 직원의 응대를 받는 것도 부담스럽다. 사용자는 자신의 모습 · 소지품 · 이동 장면에 맞는지 확인하기 위해 여러 페이지와 후기를 직접 대조한다.

### 해결

> MCM SCENE FIT은 사용자가 고른 가방을 자신의 모습과 장면에 먼저 적용하고, 수납 · 이동 · 반복 활용 조건을 검증한 뒤, 확인할 내용이 담긴 Fit Pass로 매장 체험까지 연결한다.

### 차별점

> 취향에 맞는 제품을 추천하는 데서 끝나지 않고, 잘 맞지 않는 점과 정보의 한계까지 보여주며, 온라인 결과를 실제 매장 체험의 입력값으로 사용한다.

### MCM 적합성

> MCM의 여행과 이동 헤리티지를 사용자의 오늘 장면과 연결하고, 기존 Concierge · 매장 경험을 디지털 사전 준비 단계로 확장한다.

### Challenge 02 적합성

> 온라인에서 가방을 발견하고 검증한 정보가 매장의 착용 · 수납 · 스타일링 체험으로 이어지므로, AI 추천 도구보다 온 · 오프라인 인터랙티브 리테일 경험에 가깝다.

## 최종 요약

MCM SCENE FIT은 많은 기능을 한 번에 보여주는 서비스가 아니라 다음 한 가지 경험을 완성해야 한다.

> 사용자가 사고 싶은 MCM 가방을 자신의 장면에서 먼저 확인하고, 온라인에서 해결되지 않는 불확실성만 매장에서 검증하게 한다.

이를 위해 구매 전 MVP는 다음 흐름에 집중한다.

**제품 선택 → 착용 미리보기 → 장면 · 조건 검증 → 대안 비교 → Store Fit Pass**

수납 게임, 자유 배경 생성, 실시간 재고, 디지털 트윈, 구매 후 다마고치는 핵심 흐름이 검증된 뒤 확장한다.
